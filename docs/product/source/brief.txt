PROJECT BRIEF

Idea title:
Review Intelligence for Multi-Outlet Businesses

Verticals:
Restaurants, hotels, clinics and retail chains.

AI depth:
LLM classification, reply generation and prompt versioning.

Description:
Collect customer reviews for every outlet, tag them by theme
(food, wait time, staff, cleanliness, price), track sentiment per
outlet over time, and draft on-brand replies for a manager to approve.
A weekly digest names the outlet and the issue that moved most.

Example use case:
A 25-outlet restaurant chain sees that one outlet's wait-time complaints
tripled after a staff change and replies to every review within a day
without a dedicated person.

Treat this as the intended use case, not evidence that the product has
already achieved these results.

FUNCTIONAL REQUIREMENTS

Roles:
- Brand admin.
- Outlet manager.

Outlet management and review import:
- Admins add outlets.
- Admins import reviews by CSV.
- CSV fields: outlet, source, date, rating, text, reviewer name.
- Implement importing through a connector interface so other sources
  can be added later.
- Keep the Google connector as an interface only.
- Do not implement live connectors.

Review classification:
- The model tags reviews in batches of 20.
- Themes come from a configurable list.
- Initial themes: food, wait time, staff, cleanliness and price.
- Include sentiment.
- Include an urgent flag for food safety, harassment and legal threats.
- Cache successful tags so each review is tagged once.

Biggest risk and requested fallback:
Batch tagging may return misaligned results for some reviews.
Use review IDs in the output schema, validate results per ID and retry
only the missing IDs.

Dashboard:
- Rating trend per outlet.
- Sentiment trend per outlet.
- Theme heatmap by outlet.
- Biggest movers week over week.
- Searchable review list.

Reply generation:
- For each review, the model drafts a reply in the brand's tone.
- The reply should use the review's language: English or Hindi.
- An outlet manager edits the draft and marks it replied.
- Replies require manager approval.
- The application does not post replies to Google.

Digest:
- A weekly digest contains movers and urgent reviews.
- It names the outlet and the issue that moved most.
- Generate it on demand.
- Send it to the local mail catcher.
